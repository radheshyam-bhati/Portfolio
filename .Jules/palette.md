## 2025-06-26 - Contextual Labels for Mapped Collection Links\n**Learning:** When using icon-only links within mapped collections (like grids or lists), standard `aria-label`s become repetitive and indistinguishable for screen reader users. Adding redundant `aria-label` or `title` attributes to elements that already contain sufficient visible text should be avoided.\n**Action:** Use dynamic, context-specific text (e.g., incorporating the item's title or ID) for `aria-label` and `title` attributes to ensure screen reader users can distinguish between multiple identical icons, while providing a native tooltip for mouse users.
