## 2025-07-06 - Dynamic ARIA Labels on Icon-only Links\n**Learning:** When using mapped collections to render cards with icon-only links (like GitHub/Live demo links in the Projects section), screen readers cannot distinguish between multiple instances of the same link on the page.\n**Action:** Add dynamic `aria-label` and `title` attributes incorporating specific item context (e.g., `title={ `GitHub repository for ${project.title}` }`) to ensure each link is uniquely identifiable.
